Conversor SPED EFD ICMS/IPI → Excel

Selecione o arquivo .txt da EFD ICMS/IPI e gere uma planilha .xlsx com uma aba para cada registro (0000, 0150, C100, C170, C190, E110…), incluindo as colunas de contexto dos registros de nível superior. Todo o processamento acontece no seu navegador — nenhum dado é enviado para a internet.

Layout de saída compatível com o modelo EfdIcmsIpi.xlsx: cabeçalhos com o nome de cada campo do Guia Prático da EFD ICMS/IPI, datas como data do Excel, valores e alíquotas como número (duas casas), demais campos como texto (preservando zeros à esquerda). Arquivos lidos na codificação Windows-1252/ISO-8859-1, padrão do SPED.
