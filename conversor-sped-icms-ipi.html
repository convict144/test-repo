Conversor SPED EFD ICMS/IPI ⇆ Excel

.txt → .xlsx: selecione o arquivo da EFD ICMS/IPI e gere uma planilha com uma aba para cada registro (0000, 0150, C100, C170, C190, E110…), incluindo as colunas de contexto dos registros de nível superior. .xlsx → .txt: selecione uma planilha nesse mesmo formato e gere de volta o arquivo texto no leiaute do SPED. Todo o processamento acontece no seu navegador — nenhum dado é enviado para a internet.

Arraste o arquivo .txt ou .xlsx aqui
ou clique para selecionar (pode selecionar vários) — a direção da conversão é detectada pela extensão
Layout compatível com o modelo EfdIcmsIpi.xlsx: cabeçalhos com o nome de cada campo do Guia Prático da EFD ICMS/IPI, datas como data do Excel, valores e alíquotas como número (duas casas), demais campos como texto (preservando zeros à esquerda). Arquivos .txt lidos e gravados na codificação Windows-1252/ISO-8859-1 com quebras CRLF, padrão do SPED. Na volta para .txt, as colunas de contexto (0000-…, C100-…) são usadas para reencaixar cada registro na posição hierárquica correta do arquivo.
